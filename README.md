# Local RAG

Локальное приложение для импорта документов, поиска по ним и чата с выбранной генеративной моделью. Индекс, SQLite и копии источников хранятся на этой машине.

## Возможности

- Импорт PDF, TXT, Markdown, статического HTML и текстовых файлов исходного кода. Веб-адреса, сетевые загрузки и OCR не поддерживаются.
- PDF обрабатывается через Poppler (`pdfinfo`, `pdftotext`). HTML разбирается без выполнения JavaScript и загрузки внешних ресурсов.
- Ограничения импорта: 256 MiB на файл и 512 MiB на один запуск индексации.
- Поиск предлагает фиксированные окна и фрагментацию по разделам. Enhanced retrieval дополнительно ранжирует найденные фрагменты локальной `qwen2.5:3b`.
- Chat хранит отдельные сессии, историю и память в SQLite. Ходы выполняются последовательно; очередь не ограничена, IP rate limit и per-user quota не реализованы. Состояние восстанавливается после перезагрузки страницы.
- Benchmark сравнивает raw и enhanced retrieval на наборе вопросов; сравнения разных моделей нет.

## Требования

- Java 17 или новее.
- Ollama с `embeddinggemma:300m` и `qwen2.5:3b` для локальных embeddings и reranking.
- Модель локальной генерации: `qwen2.5:3b`, `qwen2.5:3b-instruct-q5_K_M` или `qwen2.5:7b`.
- Poppler для PDF. `DEEPSEEK_API_KEY` нужен только при выборе DeepSeek Cloud.

## Запуск на этой машине

```bash
./gradlew run
```

Откройте `http://127.0.0.1:8765/`, добавьте файлы и подтвердите индексацию. Затем задайте вопрос во вкладке коллекции или создайте Chat-сессию. Для остановки нажмите `Ctrl+C`.

Baseline отправляет модели только вопрос. RAG использует найденные фрагменты и показывает citations с источником и местоположением. Если подтверждающих фрагментов нет, RAG возвращает сообщение о недостатке источников. Ошибка выбранной модели не включает автоматический переход к другому провайдеру.

## Модели и данные

В Chat каждая сессия хранит собственный выбор provider/model. Локальная генерация Ollama использует `num_thread=8`, `temperature=0`, `num_predict=768` и `num_ctx=4096`. Обычный ответ по умолчанию краткий. Исчерпание лимита возвращает явную ошибку; обрезанный ответ не сохраняется.

По умолчанию данные находятся в `~/.local/share/local-rag`: SQLite — `local-rag-v11.sqlite`, копии импортированных файлов — в `sources/`. Путь можно изменить через `LOCAL_RAG_DATA_DIR`. Данные на диске не шифруются приложением.

Поиск и reranking всегда локальны. При выборе Cloud-провайдера модели передаются вопрос, выбранный контекст беседы, память и найденные фрагменты. Ключ передавайте через окружение; не сохраняйте его в файлах, базе или логах.

## Benchmark

JSON содержит массив `questions`; каждая запись — `id`, `question`, `expectedFacts` и `expectedSources` с существующим `sourceId` и местоположением фрагмента. Для PDF указываются страницы, для текстовых файлов — строки, для HTML — заголовок раздела. Например:

```json
{
  "questions": [
    {
      "id": "q01",
      "question": "Где описаны основные маркеры?",
      "expectedFacts": ["В документе перечислены маркеры маршрута."],
      "expectedSources": [
        {
          "sourceId": "00000000-0000-4000-8000-000000000000",
          "location": { "lineStart": 12, "lineEnd": 16 }
        }
      ]
    }
  ]
}
```

В примере `sourceId` синтетический; замените его UUID существующего источника. Для синтетической коллекции используйте `examples/synthetic-observatory.md` или создайте её командой:

```bash
python3 examples/create_synthetic_corpus.py /tmp/synthetic-observatory.md
```

## Доступ по домашней Wi-Fi-сети

LAN-режим разрешён только для адреса `192.168.2.160:8767`. Для текущего demo-host Ollama слушает `127.0.0.1:11435`:

```bash
LOCAL_RAG_OLLAMA_URL=http://127.0.0.1:11435 \
LOCAL_RAG_BIND_ADDRESS=192.168.2.160 \
LOCAL_RAG_PORT=8767 \
./gradlew run
```

В этом режиме доступен только Ollama; Cloud-провайдеры отключены, а Ollama остаётся на loopback. HTTP работает без TLS и входа: любой клиент этой сети получает полный доступ к коллекции, а трафик не шифруется. Используйте только доверенную домашнюю сеть и не настраивайте port forwarding.

`LOCAL_RAG_PORT`, `LOCAL_RAG_BIND_ADDRESS`, `LOCAL_RAG_OLLAMA_URL` и `LOCAL_RAG_DATA_DIR` можно переопределять в пределах разрешённой конфигурации LAN-режима.
